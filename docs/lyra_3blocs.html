🔧 Stack Technique

🧠 LLM

  • Intent + LYRA: Llama 3.2 3B (partagé)
  • EPHAISTOS: Qwen 2.5 Coder 7B
  • Whisper: faster-whisper (CUDA)

🔍 RAG

  • Semantic: ChromaDB + all-MiniLM-L6-v2
  • Keyword: BM25
  • TOON: Compression ~40%

🌐 MCP (70 outils)

  • FEDORA (17), CATT (15), HUE (24), TV (14)

💾 VRAM (~10.5 GB)

  • EPHAISTOS: ~5 GB
  • LYRA+Intent: ~2.5 GB
  • Embeddings: ~0.5 GB
  • Whisper: ~1.5 GB

🔄 Flux : 3 BLOCS

  1. BLOC 1 - INPUT (gauche): User → Whisper STT
  2. BLOC 2 - CENTRE (milieu): TOUS les éléments de traitement
    • INTENT : Classification
    • PATHS : KNOWLEDGE (info) + ACTION (action)
    • BACKEND : MCP + STORAGE
  3. BLOC 3 - OUTPUT (droite): Response → User

✅ Structure 3 blocs : INPUT | CENTRE (tout dedans) | OUTPUT
