🔄 🔄 Flux de données

  1. Input: L'utilisateur émet une commande vocale
  2. Transcription: Whisper convertit l'audio en texte
  3. Analyse: LYRA comprend l'intention et génère les commandes MCP
  4. Exécution: Les serveurs MCP exécutent les actions
  5. Response: LYRA formate et renvoie le résultat

💬 💬 Exemples de commandes

  • "Démarre la VM preprod-09"
  • "Allume les lumières de la chambre"
  • "Monte le volume de la TV"
  • "Crée un backup de la VM prod-01"
  • "Caste cette vidéo YouTube sur la TV"
