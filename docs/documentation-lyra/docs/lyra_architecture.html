  • Semantic: ChromaDB + all-MiniLM-L6-v2
  • Keyword: BM25
  • TOON: Compression ~40%

  • DENON (10), FEDORA (17), CATT (15), HUE (24), TV (14)

  • LYRA+Intent: ~2.5 GB
  • Embeddings: ~0.5 GB
  • Whisper: ~1.5 GB
