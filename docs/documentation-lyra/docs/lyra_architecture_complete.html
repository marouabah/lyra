🔧 Stack Technique

🧠 LLM & IA

  • Intent Classifier: Llama 3.2 3B (classification demande/info/discussion)
  • LYRA Frontend: Llama 3.2 3B (dialogue et formatage)
  • EPHAISTOS Backend: Qwen 2.5 Coder 7B (analyse specs MCP)
  • Whisper STT: faster-whisper (CUDA GPU acceleration)
  • Piper TTS: fr_FR-upmc-medium (voix française)

🔍 RAG & Recherche

  • Semantic Search: ChromaDB (vector database)
  • Embeddings: all-MiniLM-L6-v2 (multilingue)
  • Keyword Search: BM25 (rank-bm25)
  • Fusion: RRF (Reciprocal Rank Fusion)
  • TOON Encoder: Token compression (~40% économie)

🌐 MCP Servers

  • FEDORA: 17 outils (VM KVM, backups)
  • CATT: 15 outils (cast YouTube, vidéos)
  • HUE: 24 outils (Philips Hue lumières)
  • TV: 14 outils (Philips TV control)

⚙️ Infrastructure

  • Backend: Python 3.12 + asyncio
  • LLM Framework: Ollama (local inference)
  • Session Storage: In-memory avec PendingChoice

💾 Ressources VRAM (~10.5 GB)

  • EPHAISTOS (Qwen 2.5 Coder 7B): ~5 GB
  • LYRA Voice (Llama 3.2 3B): ~2.5 GB
  • Intent Classifier (Llama 3.2 3B): ~2.5 GB (partagé avec LYRA)
  • Embeddings (all-MiniLM-L6-v2): ~0.5 GB
  • Whisper (faster-whisper): ~1.5 GB (mode vocal)
  • Total: ~10.5 GB (RTX 3080 Ti 12GB)

Note: Intent Classifier et LYRA Voice utilisent le même modèle Llama 3.2 3B chargé une seule fois.

🔄 Flux de données

📥 PATH: Info/Discussion

  1. User → Commande texte ou vocale
  2. Intent Classifier → Détecte "info" ou "discussion"
  3. LYRA Voice → Génère réponse conversationnelle
  4. Response → Formatage final
  5. TTS → Synthèse vocale (optionnel)

⚡ PATH: Action MCP

  1. User → Demande d'action ("démarre VM", "allume lumières")
  2. Intent Classifier → Détecte "demande"
  3. RAG Hybrid → Recherche specs MCP (semantic + keyword)
  4. TOON Encoder → Compression des specs (~40%)
  5. EPHAISTOS → Analyse specs et génère tool call JSON
  6. HESTIA → Exécute l'action MCP
  7. MCP Servers → FEDORA/CATT/HUE/TV exécutent
  8. LYRA Voice → Formate le résultat
  9. Response → Retour utilisateur

Lignes pointillées: Session Memory fournit le contexte à chaque étape

⚡ Performance

⏱️ Temps de réponse moyens

  • Intent Classification: ~50-100ms
  • RAG Search (Hybrid): ~200-400ms
  • TOON Encoding: ~10-20ms
  • EPHAISTOS Analysis: ~1-3 secondes
  • MCP Execution: Variable (50ms-60s selon action)
  • LYRA Formatting: ~100-300ms

🚀 Path Info/Discussion: ~300-500ms

⚡ Path Action MCP: ~2-4 secondes + temps MCP
