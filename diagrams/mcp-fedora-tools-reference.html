📌 Légende & Conventions

🟢 SÛRE - Opération en lecture ou sans risque
🟡 MODÉRÉE - Attention requise selon paramètres
🔴 CRITIQUE - Opération destructive irréversible
⏱️ ASYNC - Exécution asynchrone (n8n/subprocess)

📍 Backend Technique

📂 Scripts Bash: /home/amineutron/dev/fedora-setup/scripts/agents/
🔧 Stack: KVM/libvirt, virsh, virt-clone, qemu-img
🔐 Sudoers: /etc/sudoers.d/lyra (passwordless sudo)
⏱️ Timeout MCP: 120 secondes
📡 Async: n8n webhook → fallback subprocess.Popen
🔔 Notifications: Discord webhook (async_complete, errors)

⚠️ Sécurité & Confirmations

  • Confirmation obligatoire pour toutes les actions MCP
  • Mode Performance: Skip pour domotique uniquement (jamais pour VM/Backup critiques)
  • Read-First: Vérification état VM avant action
  • Règle Double Clé: Snapshot requis < 5 min avant vm_destroy
