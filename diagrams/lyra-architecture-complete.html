🎯 Composants Clés

🔍 RAG Hybrid
ChromaDB (semantic) + BM25 (keyword) + RRF Fusion
⚙️ EPHAISTOS
Qwen 2.5 Coder 7B - Analyse specs MCP + Extract args JSON
🗣️ LYRA Voice
Llama 3.2 3B - Clarification + Formatage réponses
🎯 HESTIA
Executor MCP + Metrics + Notion logging optionnel
🔧 MCP Servers
6 serveurs: FEDORA, TV, HUE, CATT, DENON, MERMAID (80 outils)

⚡ Flux Typique: "démarre preprod-09"

  1. Input: User dit "démarre preprod-09" (vocal Whisper ou texte)
  2. Intent: IntentClassifier → "demande" (action MCP)
  3. RAG: Semantic + BM25 → Top 5 specs → TOON encode
  4. EPHAISTOS: Analyse specs → {"name": "vm_start", "arguments": {"vm_name": "preprod-09"}}
  5. Confirmation: User approve [O/n/d]
  6. HESTIA: Execute MCP fedora.vm_start
  7. MCP: Bash script → virsh start preprod-09 → IP 192.168.122.146
  8. LYRA: Format: "✅ preprod-09 est démarrée (IP: 192.168.122.146)"
  9. Output: Texte + optionnel TTS Piper

🎬 Fonctionnalités Spéciales

  • Session Memory: Contexte 10 tours + PendingAction pour clarifications multi-tour
  • TOON Encoding: Compact specs MCP ~40% tokens avant EPHAISTOS
  • Async Operations: vm_clone, backup_create → n8n webhook → subprocess fallback
  • Discord Notifications: Callbacks async + erreurs critiques
  • Scene Iron Man: 7 phases 33s synchronisant TV + Hue (state machine IDLE→STABLE)
  • Mode Performance: Skip confirmation pour domotique (jamais VM/backup dangereux)
  • HDMI ARC Redirect: tv.volume_* → denon.* automatique si home cinema actif

💻 Stack Technique

🧠 LLM Backend: Qwen 2.5 Coder 7B (EPHAISTOS) ~5 GB VRAM
🗣️ LLM Frontend: Llama 3.2 3B (LYRA) ~2.5 GB VRAM
🔍 RAG: ChromaDB + BM25 (rank-bm25) ~0.5 GB
📊 Embeddings: all-MiniLM-L6-v2 (sentence-transformers)
🎤 STT: faster-whisper base CUDA ~1.5 GB
🔊 TTS: Piper fr_FR-upmc-medium
🔧 MCP: stdio protocol multi-serveurs
📡 Async: n8n webhooks + subprocess.Popen
🔔 Notifications: Discord webhooks
💾 Database: ChromaDB (vector store) + session state
⚙️ Config: YAML + Python dataclasses
🐍 Python: 3.12 (venv) asyncio + rich console
